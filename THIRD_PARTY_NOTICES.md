# Third-party notices and architectural references

GE360 Agent Control Center is a new lightweight implementation. The initial source code in this repository was written specifically for GE360 rather than copied wholesale from the projects below.

The design was informed by these public projects:

- Agent Deck by Ashesh Goplani — MIT License — terminal/session management patterns for AI coding agents.
- Agent of Empires by Nathan Brake and contributors — MIT License — persistent tmux agents and Web/mobile control concepts.
- AgentBox by Marco D'Alia and contributors — MIT License — isolated agent runtime and Codex authentication lifecycle concepts.
- DevOps AI Skill Pack by its contributors — studied only as a conceptual example of DevOps skills. No source code from that repository is incorporated by this initial implementation because a license file was not available at the standard repository path during review.

OpenAI Codex is a separate product and is not redistributed by this repository. The installer uses the official Codex installer when Codex is not already present.

If future commits copy or vendor third-party source, retain the corresponding copyright and license text in this file or in a dedicated vendor notice.
